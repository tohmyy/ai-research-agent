# Resetchy — FastAPI AI Engine

Phase 0 scaffold only. This service will own research, RAG, generation,
evaluation, channel adaptation, and every outbound third-party integration
(Claude, Firecrawl, Voyage, LinkedIn, X, SendGrid) per `TDD.md` at the repo
root. No pipeline logic is implemented yet — see `BUILD-PLAN.md` for the
phased build order.

> **Python 3.11+ is required and was not detected on this machine when this
> scaffold was created — install Python before running these commands.**

## Setup

From the `api/` directory:

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure environment variables
cp .env.example .env
# then fill in .env with real values as each integration comes online
# (all keys are optional for Phase 0 — the app boots with everything blank)

# 4. Run the app (factory pattern — see app/main.py:create_app)
uvicorn app.main:create_app --factory --reload
```

## Verify

With the server running (default `http://127.0.0.1:8000`):

```bash
curl http://127.0.0.1:8000/health
# {"status": "ok"}
```

Interactive API docs are also available at `http://127.0.0.1:8000/docs`
(Swagger UI, auto-generated by FastAPI) once the server is running.

## Project layout

```
api/
  app/
    main.py            # FastAPI app factory (create_app) + /health
    config.py           # pydantic-settings Settings, reads env vars from TDD.md §12
    db/                  # async SQLAlchemy engine/session plumbing (no ORM models yet)
    research/            # Firecrawl search + scrape                — Phase 2
    rag/                 # chunking, Voyage embeddings, pgvector    — Phase 2
    generation/          # planning + multi-option drafting (Claude) — Phase 3
    evaluation/          # rubric evaluation + bounded revision loop — Phase 4
    channels/            # LinkedIn/X/newsletter adaptation          — Phase 6
    publishing/          # Publisher interface + placeholder impls   — Phase 7
    notifications/       # SendGrid notification service             — Phase 7
  requirements.txt
  .env.example
  Dockerfile
```
